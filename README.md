# Indian Job Market Analysis

## 📌 Project Overview

This project analyzes the Indian job market to identify trends in job postings, locations, required skills, companies, experience requirements, and salary patterns.

The project uses **Python, SQL (SQLite), Excel, and Power BI** to clean, analyze, and visualize the job market data.

## Dataset

The cleaned dataset used in this project is available here:

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* SQL (SQLite)
* Excel
* Power BI
* Jupyter Notebook

## 🔍 Project Workflow

1. Cleaned and prepared the job market dataset.
2. Performed Exploratory Data Analysis (EDA) using Python.
3. Used SQL queries to analyze job postings and technical skills.
4. Created visualizations to identify important job market trends.
5. Built an interactive Power BI dashboard for business insights.

## 📊 Key Insights

* Bangalore has the highest number of job postings among the analyzed locations.
* Hyderabad and Pune are also major job markets.
* SQL, Python, Excel, AWS, and Azure are among the frequently required technical skills.
* Job postings vary significantly in their experience requirements.
* Salary information is available for only a portion of the job postings.

## 📈 Power BI Dashboard

The dashboard provides an interactive view of:

* Total Job Postings
* Top Job Locations
* Top Technical Skills
* Top Companies
* Experience Requirements
* Average Experience

## 🎯 Conclusion

This analysis provides an overview of the Indian job market and highlights the locations, skills, companies, experience requirements, and salary patterns associated with job opportunities. The project demonstrates the complete data analytics workflow from data cleaning and EDA to SQL analysis and dashboard creation.
